# Reproducibility and code-review notes

This is a credited study/archive. The supplied MATLAB scripts and Siemens excerpt were **not executed in MATLAB, PLCSIM, TIA Portal or on a real motor** during GitHub preparation.

## Source vs. thesis differences

1. **Active plant vs. description:** The original optimization script's active equations use `K_m = 38.7`, `tau1 = 1.07`, `tau2 = 0.27` and delay `L = 0.03` with a Padé approximation. Earlier comments describe a first-order plant `35.2/(1.1s+1)`, and a printed caption uses yet another parameter set. The *active MATLAB equations* should be used when reporting a rerun.
2. **Voltage limit:** The code sets `V_max = 15`, although some comments and one plot title refer to 24 V. Avoid treating those labels as measured settings.
3. **PSO settings:** The shared MATLAB optimizer sets **80 particles and 80 iterations** for each controller, whereas the thesis tables describe **50/100 for PID and 80/150 for FOPID**. Re-running the uploaded script will not necessarily reproduce reported thesis gains.
4. **Cost time windows:** The supplied PID cost function simulates **0–8 seconds**, and the FOPID cost function **0–5 seconds**. The final visual comparison script uses 0–5 seconds for both; the optimization objectives are not numerically matched as written.
5. **MATLAB script layout:** The original text contains the `get_metrics` local function before more script statements. In [`optimization_controllers.m`](../matlab/optimization_controllers.m), that function is relocated to the script end to meet MATLAB script-function placement rules. Its calculation logic was not deliberately altered; the untouched text is available in [`source_original/`](../source_original/).
6. **PLC scope:** The SCL file computes its motor speed from a **first-order motor model** and does not supply the original TIA Portal FB/DB project or physical input/output configuration.
7. **Toolbox dependency:** The MATLAB optimization files call `fotf`, requiring a compatible fractional-order control toolbox (e.g., the version used for the original work).

## To reproduce results properly

1. Record the exact MATLAB/Control System Toolbox and FOTF/FOMCON versions.
2. Compare active plant dynamics and cost-function simulation intervals with the intended thesis experiment.
3. Run PID and FOPID optimization using a reproducible seed and consistent horizons.
4. Save measured performance metrics, PSO convergence curves, configuration files and raw data.
5. For PLC verification, acquire the original TIA Portal project or create a clearly labeled reconstruction, simulate it in PLCSIM and validate a complete physical I/O design before using real motor hardware.

The thesis numerical tables in [THESIS_RESULTS.md](THESIS_RESULTS.md) are **reported research measurements**, not generated by this GitHub repository. Treat any new plots as separate outputs with their own runtime/configuration notes.
